# Abdallah Portfolio V5 — نسخة خفيفة جاهزة لـ GitHub

هذه حزمة الموقع الكاملة للتشغيل، وليست تحديثًا على شكل صورة فقط.

- تشمل Home وAbout وSkills وCertificates (8 شهادات) وProjects وContact.
- تستخدم صورة البروفايل ذات الذراعين المتقاطعتين في `assets/abdallah-hero-portrait-v5.webp`.
- الصورة بصيغة WebP **بدون فقد**: كل بكسل مطابق تمامًا لصورة العرض PNG السابقة. لم تُعدّل ملامح الوجه.
- أُزيلت نسخ الصور القديمة غير المستخدمة من **هذه الحزمة فقط** لتقليل حجم التنزيل؛ صورك الأصلية المرفوعة للمحادثة لم تُمس.
- بقي تصميم V5 الكحلي والبرتقالي وروابط شهادات Anthropic ووظائف الموقع كما كانت.

## النشر
1. فك ضغط الملف ZIP.
2. افتح المستودع `https://github.com/afarhat97/abdallah-portfolio` على الفرع `main`.
3. ارفع **محتويات** المجلد (الملفات والمجلد `assets`) إلى جذر المستودع. لا ترفع ZIP نفسه.
4. اعتمد التغييرات بـ Commit changes.
5. افتح `https://afarhat97.github.io/abdallah-portfolio/` للتأكد من النتيجة.

لا تحتاج حذف الصور القديمة من مستودع GitHub، فهي لن تؤثر على عمل النسخة الجديدة. احتفظ بملف النسخة السابقة احتياطًا.
